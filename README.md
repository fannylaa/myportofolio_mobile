# Portfolio

Proyek Flutter untuk tutorial Basic Flutter PBP. Halaman utama menampilkan kartu informasi mahasiswa dan tiga kartu aksi yang memunculkan `SnackBar` saat ditekan.

## Menjalankan aplikasi

```powershell
flutter pub get
flutter run -d chrome
```

Atau pilih perangkat Android yang tersedia dan jalankan `flutter run`.

## Data mahasiswa

Sebelum mengumpulkan tugas, ganti nilai `npm`, `nama`, dan `kelas` di `lib/menu.dart` dengan data milikmu.
